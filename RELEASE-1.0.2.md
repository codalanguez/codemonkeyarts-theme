# Signal Lab 1.0.2 — Pixel mascot and theme showcase

Adds the user-supplied monkey's tech-styled pixel-art derivative as the site header logo and Signal Lab theme mascot. The transparent mark keeps its gold/brown palette and adds cyan glasses, a circuit collar and a small magenta accent.

Signal Lab is now featured alongside Haunted Tech on the Lab homepage, with a dedicated `/signal-lab/` showcase, preview screenshot, features, live demo link and navigation entry. Editable listing content is preserved in `content/`; installing the theme does not import pages.

The logo source reference was supplied by the site owner. Theme code licensing does not grant rights to third-party reference artwork or brand assets.
